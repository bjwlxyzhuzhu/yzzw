- 测试：`npm test`。核心引擎测试沿用原样例数据，见 `tests/test.env`。
- 作品简介：`作品简介.md`；参赛与收费方案：`docs/国际中文版参赛与商用方案.md`。

## 运行环境

- Node.js ≥ 22.13（开发与测试使用 v26.4.0）。**零第三方依赖**：`node:http`、`node:sqlite`、`node:crypto`，无需 `npm install`。
- 数据库：SQLite 单文件（默认 `data/yanzhi.db`）。

## 启动

```bash
npm run init-admin -- --login admin
```

按提示设置管理员密码（≥8 位，含字母和数字）。系统**不内置任何默认密码**；也可以用环境变量 `YANZHI_ADMIN_PASSWORD` 非交互创建。管理员默认不领取教师积分；如需同时是教师，加 `--also-teacher`。

```bash
npm start
```

打开 `http://127.0.0.1:8787/`（教师入口 `/login`，管理员入口 `/admin/login`）。管理员在“教师管理”中创建教师账号，系统生成一次性临时密码，教师首次登录必须修改密码。也可以用命令行创建：

```bash
npm run cli -- create-teacher --login t01 --name 张老师
```

## 环境变量

见 `.env.example`。常用：

| 变量 | 说明 |
|---|---|
| `PORT` / `HOST` | 默认 `8787` / `127.0.0.1`（仅本机访问；本期不授权公开部署） |
| `YANZHI_DATA_DIR` | 数据目录，默认 `./data` |
| `YANZHI_MASTER_KEY` | API Key 加密主密钥（32 字节，64 位十六进制或 base64）。未设置时在数据目录生成 `master.key`（仅限开发）。**正式部署必须设置并妥善保管，不要提交到代码库** |

| `YANZHI_ALLOW_HTTP_LOCAL` | 仅测试用：允许模型 `base_url` 使用本机 http |

## 模型配置（管理员）

后台“模型与 API Key”中新增配置（表单默认预填 DeepSeek：OpenAI 兼容接口、`https://api.deepseek.com`、模型 ID `deepseek-v4.1-flash`；请以 DeepSeek 官方文档核对模型 ID）：

- 接口类型：`OpenAI 兼容（/chat/completions）` 或 `Anthropic Messages（/v1/messages）`。国内多数模型服务提供 OpenAI 兼容接口。
- `base_url` 必须是 https，不能包含凭据或查询参数；模型ID、并发上限、超时、max_tokens、教师积分费率（每次成功调用扣几分）。
- API Key 只提交、不回显；以 AES-256-GCM 加密存储，页面/接口/日志/导出只显示“已配置 · 尾号”。保存、轮换、移除、连接测试都记入审计。
- 连接测试会产生真实 API 请求，可能有真实费用（不计入教师积分）。
- 未配置或停用时，教师端“真实模型”选项不可用并显示原因；**系统不会用预设脚本冒充模型回复**。

## 积分规则（摘要）

- 新教师账号一次性获得初始积分（默认 100，管理员可调整“新账号赠送值”，只影响之后新建的教师）。无周期赠送、无充值。
- 真实模型每次**成功完成并通过格式校验、已持久化**的回复按费率计费；一轮研讨可能包含多次调用，按实际调用数计费。
- 开始前显示“预计最多 N 次调用，最多 N 积分”，按预算预占；结束/取消/失败释放未用部分。失败、中断、空输出、格式错误不扣分。
- 查看、编辑、流转、导出、评分与预设演示不收费。
- 账本不可覆盖：初始赠送、管理员分配/扣减、预占、结算、释放、冲正均有唯一幂等键。

## 两种执行方式

| | 预设演示 | 真实模型 |
|---|---|---|
| 教学研讨 | 组长分派/轮询/质询流程真实执行；段落内容为基于课程输入的**模板骨架**，标注“演示骨架” | 各角色教师智能体分段生成、跨专业质询、修订、组长整合，产物标注“AI 辅助草案，须经教师审核” |
| 模拟课堂 | 学生参与由**真实的带种子随机调度器**决定；台词来自预设句库，标注“预设演示” | 同一调度器决定谁、何时、以何种动作发言，由模型按学生可见材料与局部记忆生成台词 |
| 积分 | 不消耗 | 按成功调用计费 |

## v3.3 修订（2026-09-24）

## v6.0 国际中文教育版“演知中文”与机构授权（2026-09-29）

同一套程序新增第三个品牌版本，面向“首届国际中文教育人工智能创新应用案例征集活动”（智能体设计应用组）以及日后面向高校的收费使用。原“演知思政”（默认）与“研思智境”（`yszj`）不受影响。

- **启动**：`npm run start:zw`，读取 `zw.env`（`YANZHI_BRAND=zw`，端口 8790，数据目录 `data-zw`）。本机账号见 `data-zw/本机账号.txt`。
- **领域替换**（`server/brand.js` 的 `terms`，`server/domain.js`）：
  - 界面、接口返回、导出文件和发给大模型的提示词里，“课程思政”类术语改为国际中文写法，如“思政元素 → 文化与交际要素”“思政版教学大纲 → 国际中文课程大纲”。只改显示与提示词，不改库中数据。
  - 教研角色改为中文教师、跨文化交际教师、测评专家、本土化教学顾问、青年教师（国际中文教育硕士）等。
  - 思政元素库换成“文化与交际要素库”，共 8 类：语音与声调、词汇与搭配、语法与句式、汉字与书写、语用与得体表达、中华文化、跨文化比较与理解、当代中国。
  - 学生智能体换成 40 位来自不同国家的**学习者智能体**，带母语与中文水平（HSK 1—6 级粗略刻画）。
    - 大模型模式：提示词要求按其水平说话，可出现符合母语背景的典型偏误。
    - 本地演示模式：有对应台词。
    - 人物均为虚构，偏误描述为教学经验性描述，不代表任何真实群体。
- **配色**：“青花”色板。服务端在输出 CSS/JS/SVG 时，把原品牌红和暖褐色调按色相映射为钴蓝，描金、青色与灰阶保持不变；Logo 另存于 `public/img/brand/zw/`。
- **机构授权**（`server/license.js`，只在 `zw` 版本生效）：
  - 平台方用 Ed25519 私钥签发 `license.json`（授权单位、席位、有效期），服务器只保存公钥 `server/license-pubkey.pem` 做验证。
  - 未安装授权时为“展示评估版”：功能完整，教师账号不超过 30 个（`YANZHI_DEMO_SEATS`）。
  - 授权有效时，按授权席位控制教师账号数。
  - 到期后有 15 天宽限期；宽限期结束后不能新建研课与演课，已有数据仍可查看和导出。
  - 管理员后台“概览”页可查看授权状态并上传授权文件。
  - 签发命令：`node server/cli.js license-issue --key <私钥.pem> --licensee 某某大学 --seats 50 --expires 2027-09-30 --out license.json`。
  - 私钥保存在代码目录之外，切勿上传。
